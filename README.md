**The World in One Day** — Saturday 21 November 2026's world news summed up in one image: a hand-drawn newspaper front page carrying 27 stories, every one of them checked against a dated original source and confirmed to have happened, or to have been first reported, on that Saturday (UTC). Three illustrated leads (COP31 runs into overtime with no deal; three Houthi missiles down over Riyadh; Peru's magnitude 6.7 quake), ten illustrated cards, a world map whose numbered pins match the story numbers, 14 one-line briefs, and a clearly labelled grey band for the Friday events behind Saturday's headlines. The page is drawn as HTML/SVG in `page.html` and rendered to `entry.png` by `render.sh`; `main.ts` delivers the PNG.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
